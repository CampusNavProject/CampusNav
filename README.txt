CampusNav — Normal Demo Version

This is a simple demo prototype using Leaflet and OpenStreetMap.
- No Google Maps API key or Google billing setup is required.
- Map background requires internet access.
- The sample markers (Starting Gate, Block 34, Library) and dashed route are illustrative demo data only.
- They are NOT verified LPU locations or official walking directions.
- Run by opening index.html in Chrome or using VS Code Live Server.
